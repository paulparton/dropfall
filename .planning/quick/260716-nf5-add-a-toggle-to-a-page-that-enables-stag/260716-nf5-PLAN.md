<objective>
Add a per-player "Use Stage Skin" toggle (default ON) to the character customization page and fix the long-standing bug where pattern skins (stripes/checks/camo/polkadot) only render in-game on the 'default' theme.

Purpose: On themed levels (beach/tron/temple/arctic/inferno) every player currently gets the stage's themed ball look (e.g. beach balls) and their chosen colour/pattern is dropped except as emissive glow. Players should be able to opt out and just use their chosen skin. Separately, the pattern rendering bug means any non-default theme silently hides pattern selections — but the customization preview shows them, so the mismatch is confusing.

Output: A single, focused edit across three files (store, Player material block, customization panel UI) that ships both fixes together, since both issues live in the same material-selection block in `src/entities/Player.js`.
</objective>
