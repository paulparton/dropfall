# Quick Task 260708-h59: Hide manual server URL UI for production Railway deploy

## Task

When Dropfall is deployed to Railway as a single service (client + server on the same origin), users should not need to see or enter a WebSocket server URL. Detect production/same-origin deployments and hide the server-address input on the connect screen and the server address display in the lobby.

## Plan

1. Add runtime detection for whether the server URL is already known (build-time `VITE_WS_URL` or non-localhost origin).
2. Hide the server address input group and help text on the online connect screen when auto-detected.
3. Hide the server address display in the online lobby when auto-detected.
4. Ensure the connect button falls back to the default URL when the input is hidden.
5. Run tests and build to verify no regressions.

## Files

- `src/main.js`
- `index.html` (no changes — existing elements toggled via CSS)
- `src/style.css` (no changes — existing `.hidden` class reused)
