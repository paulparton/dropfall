# Phase 12 Plan 01: Combat Foundation Vertical Slice

## Objective

Upgrade the playable greybox into the first combat-feel slice without adding content dependencies or coupling local input to future authority.

## Tasks

1. Expose normalized boost readiness, active boost state, speed, and movement state from the fighter contract.
2. Add speed-dependent fighter impact impulses with per-pair contact gating so collisions feel decisive without impulse spam.
3. Improve input direction retention and edge control while preserving physical momentum.
4. Harden ring-out resolution and transition timing so each round scores at most once.
5. Surface combat state in the HUD and document the new controls/tuning contract.
6. Build the editor target with no hot reload, relaunch PIE, inspect logs, and visually verify a playable match.

## Verification

- `DropfallArenaEditor Mac Development` builds with `-NoHotReloadFromIDE`.
- PIE starts and `IsPIERunning` returns true.
- HUD shows boost readiness for both fighters.
- Repeated collisions do not generate engine errors or repeated same-frame scoring.
- Git diff contains only v4.0 planning and Arena implementation changes.
