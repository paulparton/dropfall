# Phase 17 — Solo ladder and match setup

Scope: Unreal Arena only. Classic work is deferred by user instruction.

Deliver a usable front end with practice AI, couch versus, and a three-match
solo ladder. A ladder starts at Rookie, advances through Rival and Ace on wins,
ends on a match loss, and permits a fresh run. Only completed runs enter the
local leaderboard. Rank by fewest rounds conceded, then fastest active play
time. Keep the best five; retain old per-tier wins and streaks when loading.

Tasks:
1. Add a tested ladder state contract and backwards-compatible saved records.
2. Integrate start, stage progression, result, retry and abandon transitions.
3. Build a responsive match setup/results HUD with keyboard, gamepad and mouse
   navigation and an honest local leaderboard.
4. Compile editor/game, run relevant tests, inspect rendered ready/results
   states and leave a playable preview open.

Acceptance: no mid-match mode/difficulty changes; no duplicate leaderboard
entry from repeated confirmation; partial/abandoned runs never rank; save
roundtrip preserves records; menu fits small and wide viewports.
