   ```css
   /* Tablet (768px-1023px): Scaled desktop layout */

       .retro-title { font-size: clamp(2.5rem, 6vw, 5rem); }
       .retro-subtitle { font-size: clamp(0.8rem, 2vw, 1.5rem); }
       .controls-display { gap: 1.5rem; padding: 1rem; }
       .control-box h3 { font-size: 1.2rem; }
       .control-box p { font-size: 0.9rem; }
       .retro-btn { padding: 0.8rem 2rem; font-size: 1.5rem; }
       #settings-content { max-width: 700px; }
       .settings-grid { grid-template-columns: 1fr 1fr; }
   }
   ```

3. **Mobile (<768px)**: Add media query for mobile-optimized layout:
   ```css
   /* Mobile (<768px): Optimized layout for small screens */
   @media screen and (max-width: 767px) {
       .retro-title { font-size: clamp(2rem, 8vw, 3.5rem); letter-spacing: 2px; }
       .retro-subtitle { font-size: clamp(0.7rem, 2.5vw, 1.2rem); letter-spacing: 8px; }
       #menu, #game-over { padding-top: max(1rem, env(safe-area-inset-top)); }
       .controls-display { flex-direction: column; gap: 0.75rem; padding: 0.75rem; }
       .control-box { width: 100%; }
       .control-box h3 { font-size: 1rem; }
       .control-box p { font-size: 0.8rem; }
       .retro-btn { padding: 0.6rem 1.5rem; font-size: 1.2rem; width: 100%; max-width: 300px; }
       button { padding: 0.8rem 1.5rem; font-size: 1.2rem; }
       #settings-content { flex-direction: column; width: 95%; }
       .settings-nav { flex-direction: row; flex-wrap: wrap; min-width: unset; }
       .settings-nav-btn { font-size: 0.8rem; padding: 0.4rem 0.8rem; }
       .settings-right-pane { max-width: 100%; }
       .settings-grid { grid-template-columns: 1fr; }
       #hud { flex-direction: column; align-items: center; padding: 10px; }
       .player-stats { width: 100%; }
       .score-display { position: relative; top: unset; left: unset; transform: none; margin: 10px 0; }
   }
   ```
