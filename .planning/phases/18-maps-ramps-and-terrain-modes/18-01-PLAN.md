# Phase 18 — core arena variety

User priority: core gameplay breadth before final presentation. Arena only.

Deliver three increasingly large maps with distinct obstacle layouts, cylinder
pillars, angled barriers and physical launch ramps. Preserve falling terrain as
an optional rule alongside a stable floor; both rules work in Practice, Couch
and Solo Ladder. Map/rule selection is setup-only and fixed for a ladder run.

Use deterministic authored layouts, actual ramp collision with flush entries,
and warning-marked floor rings that drop with their supported obstacles. Reset
all collision/geometry each round. Scale the shared camera without changing its
direction or the camera-relative input contract. Bots avoid solid obstacles and
retreat from warning edges. Rank each map/rule separately, preserving legacy saves.

Validation: editor/game builds, automation for layout sizes, spawn clearance,
ramp geometry/collision, stable-vs-collapse floor collision, resets and save
partitioning; rendered previews of all three maps; actual airborne ramp traversal.
Do not claim final production art, complete AI pathfinding or physical-controller
coverage from these checks.
