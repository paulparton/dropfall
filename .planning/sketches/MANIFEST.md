# Sketch Manifest

## Design Direction
Elevate the Dropfall player setup screen from a utility config panel to a AAA game moment. The screen should feel like stepping into a tournament lobby — exciting, polished, with personality. Five directions explored: Nintendo's warm character-select energy (Mario Kart), sleek competitive esports minimalism (Rocket League), colorful ink-personality fun (Splatoon), oppressive gothic atmosphere (Elden Ring), and clean hero gallery professionalism (Overwatch).

## Reference Points
- Mario Kart 8 Deluxe — character selection grid, warm festive palette
- Rocket League garage — dark arena aesthetic, neon glow, esports minimalism
- Splatoon Equip screen — ink color personality, fresh gear culture
- Elden Ring character creation — atmospheric, lore-rich, split-screen
- Overwatch hero select — gallery grid, team composition view, lock-in flow
